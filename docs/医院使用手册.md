# SURS 医院使用手册

## 1. 首次激活

1. 双击 `SURS.App.exe`。
2. 在首次激活页面输入交付单上的三项内容：
   - 激活卡号（以 `SURS2.` 开头的完整长字符串）
   - 账号（例如 `hos01`）
   - 密码
3. 点击“激活并登录”。

激活成功即开始计时：自该电脑首次激活当刻起 7 天，即 168 小时。

注意：

- 卡号必须完整，可以带空格或换行粘贴。
- 账号或密码错误时只提示“账号或密码错误”，不会启动软件，也不会消耗授权卡。
- 不要把卡号粘贴到密码框。

## 2. 日常登录

首次激活后，每次启动只显示账号和密码。输入交付单上的账号与密码即可登录。软件不提供“记住我”，每次启动都需要登录。

## 3. 查看授权期限

登录页会显示类似：

```text
本授权自 2026-10-29 12:00 起 7 天，至 2026-11-05 12:00 到期，剩余 7 天。
```

剩余天数按到期时刻向上取整显示。到期后软件停止使用。

## 4. 到期续期

到期后请联系甲方授权管理员领取**新卡**。在续期页输入：

- 新激活卡号
- 原账号
- 新交付单上的密码（如变更）

新卡激活后重新计算一个完整窗口。旧卡不能在同一台电脑再次使用。

## 5. 授权安全

- 同一张卡可以在不同电脑分别激活，但同一台电脑只能使用一次。
- 下一家电脑使用同一张卡时，会从该电脑首次激活时刻独立起算。
- 修改系统时间会触发回拨保护。
- 删除或篡改本机授权数据会导致软件停止运行。
- 不要手工修改 `%LOCALAPPDATA%\SURS\License` 或注册表中的授权状态。

## 6. 常见问题

### “账号或密码错误”

核对交付单中的账号和密码，注意大小写、标点和空格。密码错误不会消费卡，修正后可重新提交。

### “激活卡号无效或已被修改”

确认粘贴了完整卡号，且没有混入其它文字。仍失败时请联系甲方重新核对或补发。

### “本机存在未到期的授权使用记录”

本机已有有效授权，不能重复激活或换卡。直接使用账号密码登录；如确需续期，请到期后使用新卡。

### “该授权卡已在本机使用过”

同一张卡在同一台电脑只能消费一次。续期必须领取新卡。

### “检测到系统时间异常”

先把 Windows 时间校准为真实时间，再重启软件。若仍失败，请联系管理员。

### “授权已到期”

软件已停用，请领取新卡续期。纯离线方案无法远程延长旧卡。

## 7. 保密提醒

交付单包含账号和明文密码，请仅限本院授权使用者保管，不要转发到公开群组、网盘或工单附件。软件本身不访问外网。
